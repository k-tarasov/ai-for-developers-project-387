## Why

Сервис «Запись на звонок» уже имеет формальный API-контракт (`spec/main.tsp`, TypeSpec → OpenAPI), но у него нет пользовательского интерфейса: гость не может выбрать слот и записаться, а владелец календаря — управлять типами событий и расписанием, не обращаясь к API напрямую. Нужен отдельный фронтенд, который работает с бэкендом строго по контракту.

## What Changes

- Добавить `frontend/` — отдельное React 19-приложение на Vite (сборка и dev-сервер), никак не связанное с бэкендом на уровне кода, только через HTTP API по контракту.
- Гостевой сценарий: список типов событий → выбор типа → просмотр свободных слотов на окно записи (14 дней) → форма бронирования (имя, телефон/email, комментарий) → подтверждение.
- Сценарии владельца: CRUD типов событий, просмотр и замена расписания по умолчанию, список предстоящих броней.
- UI на shadcn/ui (Tailwind CSS) — компоненты копируются в проект; подключить shadcn MCP Server для работы ИИ-агентов с компонентами.
- Типобезопасный API-клиент, сгенерированный из OpenAPI-контракта (`spec/tsp-output`), — единственная точка обращения к бэкенду.
- Prism (mock-сервер по OpenAPI-контракту) для разработки и проверки фронтенда без запущенного бэкенда; dev-прокси Vite для работы с реальным бэкендом на `localhost:8080`.
- Цели в корневом `Makefile`: линт, тесты, сборка фронтенда (по правилам AGENTS.md).
- Обработка ошибок API по контракту (400/404/409 с кодами) с понятными сообщениями в интерфейсе.

## Capabilities

### New Capabilities

- `frontend-app`: веб-интерфейс сервиса бронирования — гостевое бронирование и управление для владельца, работающий только через API по контракту и корректно работающий с отдельно запущенным бэкендом.

## Impact

- **Код**: новая директория `frontend/` (React 19, Vite, TypeScript, shadcn/ui, Tailwind CSS). Бэкенд (`backend/`) и контракт (`spec/`) не меняются.
- **API**: фронтенд потребляет существующий контракт `spec/main.tsp` (`/event-types`, `/event-types/{id}/slots`, `/schedule`, `/bookings`); изменений контракта не требуется.
- **Зависимости**: Node.js, Vite, React 19, Tailwind CSS, shadcn/ui, Prism (dev-инструмент), генератор API-клиента по OpenAPI.
- **Инфраструктура**: корневой `Makefile` (цели lint/test/build для frontend), конфигурация shadcn MCP Server для агентов.
- **CORS**: бэкенд должен разрешать запросы с origin dev-сервера Vite (фиксируется как требование к интеграции; реализация — на стороне бэкенда отдельной задачей, либо через dev-прокси Vite без CORS).
