## Context

Фронтенд покрыт юнит/компонентными тестами (Vitest), бэкенд — in-memory Go-сервис по OpenAPI-контракту. e2e-проверок нет. Тесты запускаются в Windows-среде (PowerShell), фронт на Vite, бэкенд отдельным процессом на `http://localhost:8080/api`.

## Goals / Non-Goals

**Goals:**
- Покрыть все use-cases (гостевой + владельческий потоки) сквозными Playwright-тестами.
- Запуск одной командой против реального бэкенда и фронтенда.
- Детерминированные фикстуры, изоляция данных между прогонами.

**Non-Goals:**
- Не менять продакшен-код фронтенда/бэкенда (кроме случайно обнаруженных багов — фикс отдельным change).
- Не покрывать юнит-логику (уже покрыта Vitest).
- Не править авто-генерируемый `hexlet-check.yml`.

## Decisions

1. **Расположение**: `frontend/e2e/` (отдельно от `src/`, чтобы не попадать под Vitest). Конфиг `frontend/playwright.config.ts`.
2. **Запуск окружения**: Playwright-хук `webServer` поднимает фронт (`vite preview`/`vite`) и бэкенд (`go run` из `backend/`) перед тестами; `baseURL` указывает на фронт.
3. **Фикстуры** (`frontend/e2e/fixtures.ts`): `ownerLoggedIn` (логин через API + установка cookie `owner_session`), `seedEventType` (создание типа события через API), `freeSlot` (вычисление свободного слота из `GET /event-types/{id}/slots`).
4. **Структура тестов**: файлы по потокам — `guest.spec.ts`, `owner.spec.ts`, `integration.spec.ts` — зеркалируют список сценариев из proposal.md.
5. **Запуск локально**: npm-скрипт `e2e` в `frontend/package.json` + цель `make e2e` в корневом Makefile.

## Risks / Trade-offs

- In-memory бэкенд теряет данные при рестарте → порядок/изоляция тестов через фикстуры внутри прогона, а не между файлами.
- Совместный старт двух процессов в Windows-PowerShell может быть нестабилен → предпочитаем `webServer` с `reuseExistingServer`.
- 429 `LOGIN_ATTEMPTS_EXCEEDED` может заблокировать последующие логины в рамках прогона → тест O1.3 использует изолированный контекст браузера / перезапуск бэкенда.
- Сетевые задержи → явные `expect(...).toBeVisible()` с таймаутами вместо фиксированных пауз.
