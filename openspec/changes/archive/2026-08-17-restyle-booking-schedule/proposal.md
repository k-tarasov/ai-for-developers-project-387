## Why

Гостевая страница записи (`book-page`) показывает свободные слоты сплошным списком по дням с горизонтальными кнопками. Это неудобно при широком окне записи: гостю нужно прокручивать длинный список дней, чтобы найти подходящую дату. Хочется перенять паттерн cal.com — компактный календарь слева для выбора дня и колонка слотов выбранного дня справа.

## What Changes

- Гостевой выбор времени переезжает с плоского списка дней на **трёхколоночный макет**: (1) информация о событии, (2) календарь на текущий месяц, (3) колонка слотов выбранного дня.
- В календаре дни, на которые нет ни одного свободного слота, показываются неактивными и недоступны для выбора; доступные дни подсвечиваются.
- Календарь показывает текущий месяц и позволяет переключаться на другие месяцы и годы (выпадающие списки месяца и года).
- При выборе дня в третьей колонке отображается только расписание этого дня в виде вертикального столбца кнопок-слотов (по возрастанию времени).
- Третья колонка (слоты) имеет собственную вертикальную прокрутку в пределах своего контейнера: при скролле прокручивается только этот столбец, страница целиком не сдвигается.
- Логика бронирования (выбор слота, форма, валидация, подтверждение, обработка `SLOT_BUSY`) не меняется — меняется только способ выбора дня и раскладка слотов.
- Данные и контракт API не меняются: используется тот же `GET /event-types/{eventTypeId}/slots`.

### Допущения (зафиксированы, не блокируют)

- По аналогии с cal.com первый доступный день (в пределах окна записи) **предвыбирается** при загрузке, и справа сразу показывается его столбец слотов; гость может переключить день в календаре.
- Над столбиком слотов отображается заголовок выбранного дня (день недели + число) и метка таймзоны (UTC), как в примере.
- Навигация по месяцам в календаре ограничена окном записи (дни вне окна неактивны).
- Выбранный слот сохраняет состояние при смене дня; если гость переключает день, выбранный слот сбрасывается (его уже нет в видимом дне).

### Modified Capabilities

- `frontend-app`: требование «Гость просматривает свободные слоты типа события» меняет способ отображения слотов — с плоского списка по дням на календарь + колонку слотов выбранного дня.

## Impact

- Код: `frontend/src/pages/book-page.tsx` (основная перестройка секции выбора времени), возможно новый презентационный компонент для колонки слотов.
- UI-зависимости: уже подключённый `react-day-picker` через `Calendar` (`frontend/src/components/ui/calendar.tsx`); новых зависимостей не требуется.
- Тесты: `frontend/src/pages/book-page.test.tsx` — сценарии выбора слота и создания брони нужно адаптировать к новой раскладке (выбор дня в календаре перед появлением слотов).
- API/бэкенд: без изменений.
